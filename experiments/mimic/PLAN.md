# 사전 계획: 초파리 흉내 코드 투자자 (2026-11-09, 결과를 보기 전에 커밋)

## 질문
"초파리 뇌 대신 파이썬 몇 줄로 같은 투자자를 만들 수 있는가?"
초파리 뇌가 거래에서 한 일이 **측정된 반응 곡선**(자극 세기별 같은 방향·반대 방향 거래 확률) 하나로 요약되는지 본다.

## 흉내 투자자 (뇌 시뮬레이션 없음)
- 결정마다 1시간 수익률 r, 자극 세기 s = min(1, |r| / 1%) (초파리와 같은 `fullScaleReturn` 0.01).
- 상승 → 왼쪽 눈, 하락 → 오른쪽 눈(초파리 기본 매핑). 왼쪽 선택 = 매수, 오른쪽 선택 = 매도.
- 확률: `experiments/market/results/response-curve/curve.json`의 **눈별(좌/우) 30회 곡선**을 선형 보간
  (`market/lib/market-model.js`의 `makeCurve`·`flyProbs`, ref 0.01). r = 0이면 자극 없음 시행 비율.
  이 곡선은 거래 기록이 아니라 따로 한 자극 시행(시드 920000~)에서 쟀으므로 비교 대상(거래 결과)과 독립이다.
- 주문 규칙은 다른 투자자와 같음(`market.simulate`). 기간마다 1만 명, 시드 9201.
- 6개 기간: STONKFLY 기간 + 5개 기간(감정 실험과 같은 설정 파일).

## 주 결과와 판정 기준
- 기간마다 차이 D = 초파리 평균 손익(저장된 실행 30·10회) − 흉내 투자자 1만 명 평균 손익.
- **주 판정**: 6개 기간의 D를 단위로 한 90% 신뢰구간(t분포, 자유도 5)이 ±$0.10 안에 완전히 들어가면
  "같다(동등)"(TOST, 유의수준 5%). 0을 포함하지만 ±$0.10을 벗어나면 "판단 불가(표본 부족)". 0을 포함하지 않으면 "다르다".
- 동등 한계 $0.10의 이유: 자본의 0.1%, 수수료로 주문 약 1.7건 차이. 초파리와 규칙 투자자의 기간별 차이(약 $0.6~$1.6)보다 훨씬 작다.

## 보조 결과
1. 실행 단위(80회): 각 실행 손익 − 그 기간 흉내 평균, 90% CI(같은 ±$0.10 기준, 실행이 기간 안에서 독립이 아니므로 보조).
2. 주문 수: 기간별 초파리 평균 vs 흉내 평균.
3. 초파리 실행의 흉내 분포 안 백분위 평균(같다면 약 50%).
4. 검정이 차이를 잡을 수 있는지 확인하는 대조: 같은 기준으로 (a) 매번 거래하는 규칙 투자자, (b) 1/3 무작위 투자자 평균(저장된 결과)과 초파리 비교 → "동등"이 나오면 안 된다.
5. 참고: 행동 비율만 맞춘 무작위 투자자(가격 안 봄, 저장된 결과)와 비교.
6. 민감도: 좌우 합친 곡선(pooled), 큰 표본 곡선(`market/results/robustness/big-curve.json`, 거래 기록에서 만든 곡선이라 순환성 있음 → 참고만).

## 해석 원칙
- "동등"이면: 이 실험에서 초파리 뇌의 거래는 반응 곡선 하나로 재현된다 = 단순한 코드로 대체 가능.
- 아니면 그대로 보고하고, 어느 기간·어떤 방향 차이인지 적는다. 결과를 본 뒤 기준을 바꾸지 않는다.
- 한계: 곡선 측정 표본이 세기·눈별 30회라 곡선 자체에 잡음이 있다(민감도 6으로 확인).
