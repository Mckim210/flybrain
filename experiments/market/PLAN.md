# 사전 계획서: 초파리 투자자들의 시장 (예비 실험)

작성 2026-10-11, **시장 시뮬레이션을 한 번도 돌리기 전에** 커밋함. 아래 값과 판정 기준은 결과를 보고 바꾸지 않는다.
바꿔야 할 일이 생기면 이 파일을 고치지 말고 SUMMARY.md에 "계획과 달라진 점"으로 따로 적는다.

## 0. 질문

가격에 반응하는 초파리 투자자가 시장의 일부를 차지하면 가격 움직임(변동성, 급등락, 폭주)이 달라지는가?
그리고 그 변화가 **같은 거래 빈도의 단순 문턱 규칙 투자자**와 다른가? (= 파리 뇌가 아니라 "추세를 따르는 규칙"만으로 설명되는가?)

## 1. 반응 곡선 측정 (뇌 시뮬레이션은 이 단계만)

`experiments/trade.js`(설정 `config/trade-stonkfly-window-fixed1pct.json`)와 같은 시행 설정을 그대로 쓴다.

| 항목 | 값 |
|---|---|
| 가중치 배율 `weightScale` | 20 |
| 자극 그룹 | `VIS_R1R6` (광수용체 R1–R6), `balance: true` |
| 준비 틱 / 측정 틱 | 20 / 50 |
| 배경 잡음 | rate 0.005, amplitude 1.0 |
| 판정 | 하행 뉴런(super_class = descending) 좌/우 발화율, 총 발화 < 10 → 무반응, \|d\| < 0.2 → 무반응 |
| 자극 세기 | 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0 × (왼쪽 눈만 / 오른쪽 눈만) 각 30회 |
| 자극 없음 | 30회 |
| 시드 | 920000 + i (i = 0..29). **모든 조건이 같은 시드** → i번째 시행끼리 배경 잡음이 같음(짝지은 비교) |

- "같은 방향" = 자극한 눈 쪽 선택(왼쪽 눈 자극 → 왼쪽 선택), "반대 방향" = 반대쪽 선택, "무반응" = none.
- 각 확률의 95% 신뢰구간: Wilson 구간(n = 30, 좌우 합치면 60).
- CLAUDE.md 대략치(0~0.1: 5%/4%/91%, 0.2~0.3: 18/0/82, 0.3~0.5: 32/0/68, 0.5 이상: 45/0/55)와 나란히 비교한다.

## 2. 시장 규칙

- 투자자 N = 500명, 거래 단계 T = 500. 시작 가격 1(로그가격 0).
- 단계 t에서 모든 투자자는 **직전 단계 수익률 r_t = ln P_t − ln P_{t−1}만** 보고 동시에 매수(+1)/매도(−1)/보유(0)를 정한다. 미래 정보 없음.
- 가격 갱신: ln P_{t+1} = ln P_t + λ × (매수 수 − 매도 수) / N + σ × ε_t, ε_t ~ 정규분포(0, 1) (뉴스 충격).
- 첫 수익률 r_1은 뉴스 충격만으로 만든다(r_1 = σ ε_0). 그 뒤 500단계 거래 → 지표는 거래로 만들어진 수익률 500개(r_2 … r_501)로 계산.
- 예산·보유량 제약 없음(초과수요 방식). 수수료 없음.

### 투자자 종류

| 종류 | 행동 |
|---|---|
| 무작위 투자자 (기본) | 매 단계 매수 0.25 / 매도 0.25 / 보유 0.5 (수익률을 보지 않음; Gode & Sunder 1993의 zero-intelligence 거래자 개념) |
| (a) 초파리 | 자극 세기 s = min(1, \|r_t\| / 기준값). 오르면 왼쪽 눈, 내리면 오른쪽 눈. 1번에서 잰 **그 눈의** 확률로 왼쪽/오른쪽/무반응을 뽑고 왼쪽 = 매수, 오른쪽 = 매도 |
| (b) 초파리 역발상 | 오르면 오른쪽 눈, 내리면 왼쪽 눈(나머지는 (a)와 같음) → 오를 때 주로 매도 |
| (c) 단순 문턱 규칙 | \|r_t\| > 문턱이면 수익률 방향으로 거래(오르면 매수, 내리면 매도), 아니면 보유. 항상 같은 행동(확률 없음) |
| (d) 참고: 역발상 문턱 규칙 | (c)와 같은 문턱, 방향만 반대. (b)를 해석하기 위한 참고용(사용자 요청 범위 밖이라 결론 판정에는 쓰지 않음) |

- 세기 사이 값: 측정한 세기(0, 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0; 0은 "자극 없음" 시행)의 확률을 선형 보간.
- 초파리 한 마리 한 마리는 매 단계 독립적으로 뽑는다(뇌는 결정마다 초기화되므로 기억 없음).
- 추세 반응 투자자 비율 f = 0, 25, 50, 75% (나머지는 무작위 투자자). f = 0%는 모든 종류에서 같은 시장(무작위만)이다.

### 파라미터 값

| 파라미터 | 기본값 | 민감도(50% 비율에서만, 한 번에 하나씩) |
|---|---|---|
| λ (가격 충격 계수) | 0.02 | 0.01, 0.02, 0.04 |
| σ (뉴스 충격 표준편차) | 0.003 | 0.0015, 0.003, 0.006 |
| 자극 기준값 | 무작위 투자자만 있는 시장(같은 λ, σ, 시드 50개 합침)의 \|수익률\| 90번째 백분위 | ×0.5, ×2 (기본 λ·σ에서 모든 비율) |
| (c)·(d) 문턱 | 아래 "문턱 맞추기" | 기준값·λ·σ가 바뀔 때마다 다시 맞춤 |
| 시드 | 조건마다 1 … 50 | 같음 |

- λ = 0.02, σ = 0.003을 고른 이유(시뮬레이션 없이 계산으로만 정함): 무작위 시장의 수익률 표준편차 ≈ √(λ²·0.5/500 + σ²) ≈ 0.0031,
  기준값 ≈ 1.645 × 0.0031 ≈ 0.005. CLAUDE.md 대략치로 초파리의 최대 순매수 비율(같은 방향 − 반대 방향)은 약 0.45이므로,
  추세 투자자 50%가 모두 포화 반응할 때 밀어 올리는 크기 λ × 0.5 × 0.45 ≈ 0.0045가 기준값과 비슷해진다
  → 50% 근처가 "약한 영향"과 "추세 고착"의 경계가 되도록(25%는 약하고 75%는 강하도록) 잡은 값.
- **문턱 맞추기**: 무작위 시장(같은 λ·σ, 시드 50개)의 수익률 전부(25,000개)에 대해
  초파리 (a)의 거래 확률 평균 F = 평균[P(같은 방향 | r) + P(반대 방향 | r)]을 구하고,
  (c)의 문턱 = \|r\|의 (1 − F) 분위수 → 같은 수익률을 보여 주면 (c)도 정확히 F만큼 거래한다.
- 난수: 시드마다 뉴스 충격, 무작위 투자자 결정, 추세 투자자 결정을 서로 다른 난수열로 뽑는다.
  같은 비율·같은 시드에서는 (a)(b)(c)(d)의 뉴스 충격과 무작위 투자자 결정이 완전히 같다(짝지은 비교 가능).

## 3. 측정 지표 (시드마다 계산 → 조건별 평균과 95% 신뢰구간)

| 지표 | 정의 |
|---|---|
| 변동성 | 수익률 500개의 표준편차 |
| 최대 낙폭 | max_t (1 − P_t / max_{s≤t} P_s) |
| 최대 상승폭 | max_t (P_t / min_{s≤t} P_s − 1) (위로 가는 거품을 보려고 추가) |
| 수익률 자기상관(1시차) | 표본 자기상관 ACF(r, 1) |
| 절대수익률 자기상관(1·5·10시차) | ACF(\|r\|, k) — 변동성 군집(Cont 2001) |
| 첨도 | 초과첨도 m4 / m2² − 3 (정규분포 = 0, 두꺼운 꼬리면 양수) |
| 가장 큰 급등 / 급락 | 한 단계 로그수익률의 최댓값 / 최솟값 |
| 가격 폭주 | 어느 시점이든 \|ln(P_t / P_0)\| ≥ 1 (시작 가격의 약 2.72배 이상 또는 0.37배 이하)인 시드 수. 기본 설정의 무작위 시장에서 500단계 랜덤워크 표준편차는 약 0.07이므로 우연으로는 거의 불가능한 크기 |

- 평균의 95% 신뢰구간: 평균 ± 1.96 × 표준오차(시드 50개). 폭주 비율은 Wilson 95% 구간.

## 4. "(a)와 (c)가 다르다"의 판정 기준 (핵심 질문)

1. **지표별**: 같은 비율·같은 설정에서 (a)와 (c)의 95% 신뢰구간이 **겹치지 않으면** 그 지표는 "다름". (폭주는 Wilson 구간으로 같은 규칙)
2. **비율별 판정**: 지표 11개(변동성, 최대 낙폭, 최대 상승폭, ACF(r,1), ACF(|r|,1·5·10), 첨도, 급등, 급락, 폭주 비율) 중
   - 2개 이상 "다름" → **다르다**
   - 1개만 "다름" → **약한 차이(우연일 수 있음)** — 지표가 11개라 하나쯤은 우연히 걸릴 수 있음
   - 0개 → **구별되지 않음(같다)**
3. **결론**: 비율 25·50·75%의 판정을 각각 보고한다. 0%는 모든 종류가 같은 시장이라 판정하지 않는다.
4. **강건성**: 50% 비율에서 λ 3단계 × (σ 기본) 와 σ 3단계 × (λ 기본) = 5개 설정, 그리고 기준값 ×0.5·×2(25·50·75%)에서
   같은 판정이 나오면 "결론 유지", 하나라도 바뀌면 바뀐 설정을 그대로 적는다.
5. 보조 지표(판정에는 쓰지 않음): 같은 시드끼리 짝지은 차이 (a) − (c)의 평균과 95% 신뢰구간.
6. (a)와 (b)의 비교도 같은 기준으로 표에 적지만, 핵심 결론은 (a) vs (c)로만 내린다.

## 5. 실제 비트코인과 비교

- 자료: `experiments/prices/btcusd_1h.csv` 종가의 1시간 로그수익률(15,363개).
- 단위와 상관없는 지표만: 초과첨도, ACF(r,1), ACF(|r|,1·5·10).
- 시뮬레이션과 길이를 맞추려고 실제 수익률을 **겹치지 않는 500개 묶음 30개**로 나눠 지표를 계산하고 평균과 95% 신뢰구간을 낸다
  (전체 15,363개로 계산한 값도 참고로 적음).
- "가장 비슷한 시장": 기본 λ·σ·기준값의 모든 조건(무작위만 + 4종류 × 3비율 = 13개)에 대해 지표마다
  \|조건 평균 − 실제 묶음 평균\|이 작은 순으로 순위를 매기고, 5개 지표의 **평균 순위가 가장 낮은** 조건.

## 6. 미리 적어 두는 한계

- 우리 시장은 단순 초과수요 방식(주문이 쌓이는 주문장, 가격 매칭, 예산 제약 없음). CLAUDE.md에 적힌 대로 Cocco 등(2017)은
  주문장 기반 인공 시장으로 알려져 있어 직접 비교는 제한적이다.
- 반응 곡선은 세기당 30회로 잰 점추정치이고, 그 불확실성은 시장 시뮬레이션에 넘기지 않는다.
- weightScale 20은 FlyWire 연결 강도를 실험용으로 20배 키운 값이다.
- λ, σ, 무작위 투자자 활동 확률은 실제 시장에서 추정한 값이 아니라 정한 값이다.
