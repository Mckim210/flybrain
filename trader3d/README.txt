FlyBrain Trader - 내 컴퓨터에서 실행하기

1. 이 압축 파일을 풀어 주세요 (오른쪽 클릭 > 압축 풀기).
2. 압축을 푼 폴더에서 START.bat 을 더블클릭하세요.
   - 검은 창이 하나 뜨고, 브라우저에 FlyBrain Trader 가 자동으로 열립니다.
   - 쓰는 동안 검은 창을 닫지 마세요. 다 쓰면 검은 창을 닫으면 끝납니다.
3. 브라우저가 안 열리면 주소창에 http://localhost:8765/trader3d/ 를 입력하세요.

모드 (화면 위쪽 첫 번째 선택 상자)
- 재생: 2026-09-10~11 실제 시세로 미리 돌려 둔 뇌 기록을 다시 틀어 줍니다.
- 실시간 · 1시간마다 결정: 소논문과 같은 설정. 코인베이스 현재가로 매 정시에 결정합니다.
- 실시간 · 1분마다 결정 (데모): 1분마다 결정. 0.1% 움직이면 최대 자극 (소논문 설정 아님).
  실시간 모드에서는 뇌를 이 컴퓨터에서 직접 계산합니다. 실제 돈은 쓰지 않는 모의 거래입니다.

"Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] > [실행]을 누르면 됩니다.
안 될 때: 검은 창에 나온 영어 메시지를 그대로 Claude에게 알려 주세요.
인터넷 연결이 필요합니다 (시세, 웹 폰트).
