FlyBrain Trader - 내 컴퓨터에서 실행하기

1. 이 압축 파일을 풀어 주세요 (오른쪽 클릭 > 압축 풀기).
2. 압축을 푼 폴더에서 START.bat 을 더블클릭하세요.
   - 검은 창이 하나 뜨고, 브라우저에 FlyBrain Trader 가 자동으로 열립니다.
   - 쓰는 동안 검은 창을 닫지 마세요. 다 쓰면 검은 창을 닫으면 끝납니다.
3. 브라우저가 안 열리면 주소창에 http://localhost:8765/trader3d/ 를 입력하세요.

모드 (화면 위쪽 첫 번째 선택 상자) - 처음 열면 "실시간 · 1분마다 결정"으로 시작합니다.
- 기록 재생: 2026-09-10~11 실제 시세로 미리 돌려 둔 뇌 기록을 다시 틀어 줍니다.
  모니터 오른쪽 위에 노란 "기록 재생" 표시가 나오고, 가격은 9월 가격입니다(지금 시세 아님).
- 실시간 · 1시간마다 결정: 소논문과 같은 설정. 코인베이스 현재가로 매 정시에 결정합니다.
- 실시간 · 1분마다 결정 (데모): 1분마다 결정. 0.1% 움직이면 최대 자극 (소논문 설정 아님).
  실시간 모드에서는 모니터에 빨간 LIVE 표시가 나오고, 뇌를 이 컴퓨터에서 직접 계산합니다.
  실제 돈은 쓰지 않는 모의 거래입니다.
- 주문 규칙은 STONKFLY와 같습니다: 1건 $10, 수수료 0.6%(모든 투자자가 같음), 하루 최대 24건.

손익 칸 (오른쪽 위, 5줄)
- 초파리 뇌 / 감정 투자자 3종 평균(처분 효과·과신·추격 매수·공포 매도) / 감정 없는 기계 투자자(오르면 사고 내리면 팜, 매번) /
  무작위 투자자 평균(1/3씩 제비뽑기) / 같은 거래량 무작위 평균(초파리만큼만 거래하는 무작위 투자자).
- 감정 투자자의 확률 값은 행동경제학 이론의 방향을 따른 가정입니다. 실시간 모드에서는 종류마다 1,000명을 지금부터 계산합니다.
  1분 모드에서는 한도 24건이 금방 차서, 그 뒤로는 한국 시각 09:00까지 모두 보유만 합니다.

모니터 차트
- 모니터 왼쪽 위 1m / 5m / 15m / 1h 를 클릭하면 봉 주기가 바뀝니다.
- "모니터 보기" 버튼을 누르면 모니터가 화면 가득 보입니다.
- 브라우저 탭을 다른 탭으로 바꿔도 실시간 거래는 계속됩니다(그동안은 애니메이션 없이 결정만 합니다).
  컴퓨터가 잠자기 상태면 그동안의 결정은 건너뜁니다.

"Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] > [실행]을 누르면 됩니다.
안 될 때: 검은 창에 나온 영어 메시지를 그대로 Claude에게 알려 주세요.
인터넷 연결이 필요합니다 (시세, 웹 폰트).
